# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.3.x   | Yes       |
| 0.2.x   | No        |
| 0.1.x   | No        |

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities.

Submit reports privately with:

* Description
* Impact
* Reproduction steps
* Suggested mitigation

Reports should include sufficient technical detail to validate and reproduce the issue.

## Scope

Examples include:

* Credential exposure or insecure default credentials
* Unsafe unattended configuration
* Config-file generation flaws (e.g. encoding, escaping, or permission defects)
* Pinned download URLs compromised or redirected (supply chain)
* Script execution vulnerabilities (shell/PowerShell injection)
* Secrets leaked into logs or generated files
* Weak qBittorrent credential handling (PBKDF2 format, iteration count, salt reuse)

## Out of Scope

* Cosmetic issues
* Documentation typos
* Feature requests
* Unsupported operating systems (e.g. 32-bit, non-Intel macOS)

Security reports will be reviewed and addressed according to severity and impact.
